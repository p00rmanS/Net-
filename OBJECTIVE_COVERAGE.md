# CompTIA Network+ (N10-009) — Objective Coverage Map

This table maps each exam objective to the lessons that teach it, so you can see
at a glance that nothing is missing. Lesson IDs match the website (`#/lesson/<id>`).

> **How this was built:** from the published N10-009 objective structure (five
> domains, 1.0 to 5.0) and a keyword audit of every lesson, glossary entry, and
> question. Before the exam, compare this table with the official objectives PDF
> from CompTIA (free on their website) and tick off anything you want more
> practice on. If you find a gap, add it to the "Gaps" section and it can be
> turned into a lesson.

## Practice and tools that support the objectives

- **Standalone question bank:** 273 questions across all five domains, plus an
  inline knowledge check in every lesson (see README for totals).
- **Mock exams, daily drill, and quizzes:** filter by domain to drill your weakest area.
- **Guided labs (7):** subnetting, VLANs, static routing, Wi-Fi capacity,
  hardening, VLSM, and ticket triage.
- **Subnet calculator and generator, port trainer, OSI game, acronym trainer,
  flashcards, glossary, and command reference.**

## Practice labs (performance-based style)

Labs 1 to 7: office subnet plan, VLAN assignment, static routing, restaurant Wi-Fi capacity,
network hardening, campus VLSM plan, ticket triage. Added later: cabling tools and connectors,
ports and protocols, interface status and counters, security device selection, Wi-Fi security
design, DHCP and DNS triage, and troubleshooting methodology.

## Gaps to keep an eye on

These are lightly covered rather than missing; check them against the official
objectives list and ask for deeper lessons if they worry you:

- Performance-based questions (PBQs): the real exam includes drag-and-drop and simulation tasks; this site approximates them with labs, ordering questions, and matching games.
- More guided labs (there are 14; the real exam is mostly simulations, so keep practicing hands-on).
